Accessibility

Accessibility statement

Last updated: May 2026

Letterhome aims to be usable by everyone, including people with visual, motor, hearing, or cognitive impairments. We target conformance with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

What we do

  • Text and interface elements meet WCAG 2.1 AA colour-contrast ratios (4.5:1 for normal text, 3:1 for large text).
  • All interactive elements (links, buttons, form fields) are reachable and operable using a keyboard alone.
  • Visible focus indicators are shown on every interactive element when navigating by keyboard.
  • Pages use semantic HTML (proper headings, landmarks, lists, labels) so screen readers can announce content correctly.
  • Form fields have explicit labels and clear error messages. Required fields are marked.
  • We honour the prefers-reduced-motion setting in your operating system or browser.
  • Images that convey information have alternative text. Decorative images are hidden from assistive technology.
  • The site is usable at 200% zoom without horizontal scrolling.

Known limitations

Accessibility is an ongoing effort. Areas we are still improving:

  • The address autocomplete dropdown on the order form is functional with a keyboard, but ARIA combobox semantics are being refined.
  • Some decorative background textures may slightly reduce contrast on older browsers that don't support modern CSS features.

If something isn't accessible to you

If you run into a page, feature, or content that isn't usable, please email us at hello@letterhome.ca with a short description of the problem and the assistive technology you're using. We aim to respond within two business days and to publish a fix as soon as we can.

Alternatives

If you'd prefer not to use the website, you can email your letter content and recipient address directly to hello@letterhome.ca and we'll process the order manually. The same pricing applies.

Standards and methods

This site is tested against WCAG 2.1 AA criteria using a combination of automated tools (axe, Lighthouse) and manual keyboard, zoom, and screen-reader testing. New pages and features go through the same checks before they're published.
