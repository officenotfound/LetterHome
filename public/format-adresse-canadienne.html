Format d'adresse canadienne

Une adresse canadienne comprend : nom du destinataire, numéro et rue, ville, abréviation de la province (2 lettres) et code postal au format A1A 1A1. Exemple : Marie Tremblay, 456 boul. René-Lévesque O, Montréal, QC H2Z 1A7.

Mis à jour en juin 2026

Format standard d'une adresse au Canada

[Nom du destinataire]
[Numéro et nom de la rue, app./bureau]
[Ville, PROVINCE  CODE POSTAL]
CANADA (si expédié de l'étranger)

Exemple concret :

Marie Tremblay
456 boul. René-Lévesque O, app. 12
Montréal, QC  H2Z 1A7
CANADA

Les règles importantes

  • Province : utilisez l'abréviation officielle à 2 lettres (voir tableau ci-dessous)
  • Code postal : format A1A 1A1 — alterner lettre-chiffre-lettre, espace, chiffre-lettre-chiffre
  • Ville et province : sur la même ligne, séparées par une virgule et deux espaces avant le code postal
  • CANADA : ajoutez cette ligne si vous envoyez de l'extérieur du Canada
  • Pas d'accents sur l'enveloppe extérieure selon les normes de Postes Canada (mais accepté)

Le code postal canadien — format A1A 1A1

Le code postal canadien est unique : il alterne lettres et chiffres sur 6 caractères, séparés en deux groupes de 3 par un espace :

  • M5V 1Z4 = Toronto, Ontario (centre-ville)
  • H2Z 1A7 = Montréal, Québec (centre-ville)
  • V6B 4N8 = Vancouver, Colombie-Britannique
  • T2P 3G5 = Calgary, Alberta

La première lettre indique la province (ex. M = Ontario, H = Québec, V = Colombie-Britannique). Ne confondez pas avec le code ZIP américain à 5 chiffres.

Questions fréquentes

Quel est le format d'une adresse canadienne?

Nom, rue, puis ville + abréviation province + code postal sur une ligne. Le code postal a le format A1A 1A1. Ajoutez CANADA si vous envoyez de l'étranger.

Comment s'écrit le code postal canadien?

Le code postal alterne lettres et chiffres : A1A 1A1. Ce n'est pas un code à 5 chiffres (format américain). La première lettre identifie la province.

Quelles sont les abréviations des provinces canadiennes?

Ontario (ON), Québec (QC), Colombie-Britannique (BC), Alberta (AB), Manitoba (MB), Saskatchewan (SK) — voir le tableau complet ci-dessus.
