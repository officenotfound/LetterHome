How to write a letter to Canada

A letter to Canada follows standard block format: your address (top-left), date, recipient's Canadian address, salutation, body, closing, and signature. The key difference from other countries is the Canadian postal code format — alternating letters and numbers: A1A 1A1.

Updated June 2026

Canadian letter format — step by step

1. Your return address (optional)

Write your name and address in the top-left corner. This is optional — return addresses are not required — but including one means the letter can be returned if undeliverable.

2. The date

Write the date below your address. Canadian convention: Month DD, YYYY (e.g. June 11, 2026). Avoid numeric-only formats like 06/11/26, which are ambiguous.

3. The recipient's Canadian address

Write the recipient's address in this order:

  1. Recipient name (and title/company if applicable)
  2. Street address and unit number
  3. City, Province abbreviation, Postal code
  4. CANADA (add this line if mailing from outside Canada)

See the full address format guide for province abbreviations and postal code format.

4. Salutation

  • Formal (known name): Dear Mr. Smith, / Dear Ms. Tremblay,
  • Formal (unknown name): To Whom It May Concern,
  • Government offices: Dear Sir or Madam, / To Whom It May Concern,
  • Personal: Dear [First Name],

5. Body

State your purpose clearly in the opening sentence. Use short paragraphs (3–5 sentences each). For formal letters, keep a professional tone. For immigration or legal letters, be precise and include relevant reference numbers (application number, file number, etc.).

6. Closing

  • Formal (known name): Yours sincerely,
  • Formal (unknown name): Yours faithfully,
  • Semi-formal: Best regards, / Kind regards,
  • Personal: Warm regards, / Love,

7. Signature

Sign your name, then print your full name below the signature. For formal letters, include your title and contact information.

Letter template — formal

[Your Name] [Your Address] [City, Country, Postal/ZIP Code] [Month DD, YYYY] [Recipient Name] [Organization/Department] [Street Address] [City, Province Abbreviation Postal Code] CANADA Dear [Mr./Ms. Last Name], [Opening paragraph — state your purpose clearly in 1–2 sentences.] [Body paragraph — provide necessary details, reference numbers, or context.] [Closing paragraph — state what action you are requesting or what you expect to happen next.] Yours sincerely, [Your Signature] [Your Printed Name] [Your Phone / Email (optional)]

Tips for letters to Canadian government offices

  • Always include your application or file number in the subject line or first paragraph
  • Use the exact mailing address from the IRCC or CRA website — offices have specific intake addresses
  • Keep a copy of everything you send
  • For IRCC: see the IRCC mailing guide for correct addresses
  • For CRA: see the CRA tax forms mailing guide

Frequently asked questions

What is the correct letter format for Canada?

Canadian letters use standard block format — return address, date, recipient address, salutation, body, closing, signature. The postal code format is A1A 1A1 (alternating letter-number-letter, space, number-letter-number).

How do I address a formal letter to a Canadian government office?

Use "To Whom It May Concern," as the salutation. Include the full department name, specific intake address, and any reference numbers in your letter. Always use the official mailing address from the government website.

Do I need a return address on a letter to Canada?

No — it's optional. See our guide on sending a letter without a return address.
