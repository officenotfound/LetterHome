Estimate the weight from the number of sheets

80gsm A4 paper weighs about 5 g a sheet. Weigh the real letter on kitchen scales if it is close to 100 g.

Prices are the 7 April 2026 stamp prices for UK letters and large letters up to 100g. Heavier large letters cost more, so check Royal Mail's price list for those.

Common questions

How much is a First Class stamp?

A First Class stamp for a standard letter is £1.80 since 7 April 2026.

How much is a Second Class stamp?

A Second Class stamp for a standard letter is 91p since 7 April 2026.

What is the largest size for a standard letter?

Up to 240 x 165 mm and 5mm thick, and up to 100g. Anything bigger or thicker, up to 353 x 250 x 25 mm and 750g, is a large letter.

Is this calculator official?

No. It uses published Royal Mail stamp prices. Check the Royal Mail price list for heavier items or other services.
