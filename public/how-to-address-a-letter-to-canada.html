How to address a letter to Canada

To address a letter to Canada: write the recipient name, street address, city, two-letter province code, and postal code (format: A1A 1A1) on the same side as the stamp. The return address goes in the top-left corner.

Updated August 2026

To address a letter to Canada, write the recipient's name on the first line, the civic number and street on the next line, and the city, two-letter province code, and postal code together on a single line — for example, OTTAWA ON  K1A 0B1. If you are mailing from another country, add CANADA in capital letters on the final line. Canada Post recommends writing the whole address in uppercase with no punctuation for the most accurate automated sorting.

The correct Canadian address format

A standard Canadian address uses four parts, top to bottom. Here is exactly how an envelope mailed within Canada should look:

JOHN SMITH 123 MAIN ST NW OTTAWA ON K1A 0B1

Domestic format — city, province, and postal code share one line, with two spaces before the postal code.

Mailing to Canada from another country

When you send from the United States, the UK, Australia, or anywhere else, keep the same block and add the destination country on the last line, in capitals:

JOHN SMITH 123 MAIN ST NW OTTAWA ON K1A 0B1 CANADA

International format — add CANADA on the final line. Never write your own country anywhere on the envelope.

How to write the address, step by step

  • Line 1 — Name. The recipient's full name. Add a company or "c/o" name on a second line if needed.
  • Line 2 — Street. Civic number, then street name and direction (e.g. 123 MAIN ST NW). Put a unit or apartment first: APT 2 - 45 KING ST W.
  • Line 3 — City, province, postal code. All on one line: VANCOUVER BC  V6B 1A1. Use the two-letter province code and two spaces before the postal code.
  • Line 4 — Country. Only when mailing from abroad — write CANADA in capitals.

Postal codes & the format that gets delivered

A Canadian postal code is always six characters in the pattern letter–number–letter number–letter–number, with a single space in the middle: K1A 0B1, V6B 1A1, M5V 2T6. Write it in capitals. The postal code is the single most important part of the address for automated sorting — double-check it before you send.

Common mistakes to avoid

  • Don't put the postal code on its own line — it belongs on the same line as the city and province.
  • Don't write the full province name — use the two-letter code (ON, not Ontario).
  • Don't add your own country — when mailing to Canada, the only country on the envelope is CANADA.
  • Don't forget the two spaces before the postal code on the city line.
