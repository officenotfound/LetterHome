How to send a letter from Sweden via Letterhome

  1. Save your document as a PDF
  2. Go to letterhome.ca/send and upload your file
  3. Enter the Canadian recipient address
  4. Pay CAD $10
  5. We print and mail your letter from Canada

How to mail from Sweden via the post office

PostNord is fast and reliable. Tracking available. Some DHL and FedEx offices for express options.

  1. Write the recipient's address using Canadian address format (include "CANADA" on the last line)
  2. Visit your local branch of PostNord
  3. Ask for international lettermail to Canada
  4. Pay postage (~SEK 25–55 (~US$2.35–5.20))
  5. For important documents, request registered/tracked mail

Canadian address format

Make sure to write the Canadian address correctly:

[Recipient Name]
[Street Address, Unit/Apt #]
[City, Province  Postal Code]
CANADA

Example: Jane Smith, 245 Queen St W, Toronto, ON M5V 1Z4, CANADA
