Where to mail a PR card renewal or replacement application

Permanent resident card renewal and replacement applications are mailed to a dedicated PO Box at IRCC's processing centre in Sydney, Nova Scotia. IRCC's own pages list PR card mail going to two closely related boxes, one for the application itself and one described as for correspondence, so confirm which your application guide points you to.

Updated October 2026

If you're a permanent resident living or travelling outside Canada and your PR card is expiring, or has already expired, you'll generally need to renew it by mail (travel document and PR card applications are frequently paper-based for applicants outside Canada).

Source: canada.ca — Case Processing Centre: Sydney, Nova Scotia

These two boxes are easy to mix up: IRCC's own pages are not perfectly consistent about which box applies to a fresh renewal application versus general correspondence on an existing file. Use the exact address printed in the application guide or form instructions for the specific PR card service you're using (renewal, replacement, or first card) rather than guessing from this page alone.

A new PR card itself is mailed by Canada Post only to a Canadian residential address, not to a PO Box, and IRCC does not courier cards internationally. If you don't have a trusted Canadian address to receive the finished card, plan for that separately from mailing the application.

Why this matters for permanent residents abroad

A valid PR card is often required to board a flight to Canada as a permanent resident.
